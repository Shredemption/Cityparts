# CityParts
Simple mod that adds a random variety of decoration blocks themed around city building. This includes:

- Pavement Blocks 🪨
- Colored Bricks 🧱
- Lamp posts and lights 💡
- Asphalt with prints 🛣️
- New colors of wood 🪵
- Traffic signs 🛑
- Random road furniture 🚧
